# Sea and Shore website

The new static website is ready to run alongside the current Wix site. Its entry page is `new-sea-and-shore.html`.

## Pages

- `new-sea-and-shore.html` — homepage
- `services.html` — services
- `quote.html` — quote request and planning calculator
- `contact.html` — contact and operational details
- `insights.html` — useful logistics information

## Before going live

Follow [DEPLOYMENT-CHECKLIST.md](DEPLOYMENT-CHECKLIST.md). Do not publish the automation service until the sending domain is verified and test emails are approved.

## Local preview

Open `new-sea-and-shore.html` in a browser. When the automated lead service is running locally, it listens on `http://localhost:8787`.
